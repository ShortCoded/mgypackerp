## §20 مرشحات عالمية — Global Filters

> جميع الشاشات التي تعرض جداول بيانات أو تقارير تستخدم المرشحات المشتركة التالية:

| المرشح | النطاق | الملاحظات |
|---|---|---|
| **الشركة — Company** | session company via `OperatingContextService` | يُحدد تلقائياً عند المستخدم只有一个 شركة، وإلا يُختار يدوياً. يُطبق عبر `OperatingScopeAccessService` مع تجاوز للمدير العام (`admin bypass`). |
| **الفرع — Branch** | session branch via `OperatingContextService` | مشروط بصلاحيات `role_company/branch/financial_period_access` pivot. |
| **الفترة المالية — Financial Period** | session period via `OperatingContextService` | يُغلق تلقائياً عند انتهاء المدة. يُطبق عبر `OperatingScopeAccessService`. |
| **التاريخ — Date Range** | شاشات التقارير وال Movements | عادةً `from_date` / `to_date` مع افتراضي الفترة المالية الحالية. |
| **العملة — Currency** | شاشات المبيعات والمشتريات | مرشح اختياري لعرض بالعملة المحددة. |
| **حالة المستند — Document Status** | شاشات الأوامر والفواتير | عرض حسب الحالة (مسودة، مقدّم، مقبول، مُلغى، مُرحّل). |

### ملاحظات التوقيت وال اللغة

| الإعداد | القيمة | المصدر |
|---|---|---|
| اللغة الافتراضية | `ar` (عربية — RTL) | `AGENTS.md`: languages ar default RTL / en LTR |
| اللغة البديلة | `en` (إنجليزية — LTR) | `AGENTS.md`: languages ar default RTL / en LTR |

## §21 جدول الإجراءات المشتركة — Shared Actions Table

> الإجراءات التالية تظهر عبر شاشات عديدة بحسب الصلاحيات المُعرّفة في `config/menu/*.php`:

| الإجراء | الصلاحية النموذجية | الوصف | الشاشات المشمولة |
|---|---|---|---|
| **عرض — View** | `{module}.view` | فتح الشاشة وعرض السجلات | جميع الشاشات |
| **إنشاء — Create** | `{module}.create` | فتح نموذج إنشاء سجل جديد | المنتجات، العملاء، الموردون، أوامر البيع/الشراء، etc. |
| **استنساخ — Clone** | `{module}.clone` | نسخ سجل موجود كنموذج جديد | المنتجات، العملاء، الموردون، العروض، etc. |
| **تعديل — Edit** | `{module}.edit` | تعديل بيانات سجل موجود | جميع شاشات CRUD |

| **ترحيل — Post** | varies | ترحيل مستند مالي/مخزني | أذون الاستلام، مرتجعات المشتريات، حركات المخزون |
| **إلغاء ترحيل — Reverse** | varies | إلغاء ترحيل مستند | أذون الاستلام، مرتجعات المشتريات، فواتير المشتريات |
| **تقديم — Submit** | varies | تقديم مستند للموافقة | طلبات الشراء، أوامر الشراء |
| **موافقة — Approve** | varies | موافقة على مستند | طلبات الشراء، أوامر الشراء، جرد المخزون، فواتير المشتريات |
| **رفض — Reject** | varies | رفض مستند مقدّم | طلبات الشراء، أوامر الشراء |
| **إلغاء — Cancel** | varies | إلغاء مستند نشط | أوامر الشراء، فواتير المشتريات، أوامر التوريد |
| **إغلاق — Close** | varies | إغلاق مستند بدون إكمال | أوامر الشراء، فواتير المشتريات، أذون المخزون بدون أسعار |
| **طباعة — Print** | varies | طباعة المستند | العروض، أوامر الشراء، الفواتير، أذون الاستلام |
| **تصدير — Export** | varies | تصدير البيانات لملف | التقارير، السجلات |
| **PDF** | varies | تصدير PDF | التقارير، السجلات |
| **التحكم برقم المستند — Document Number Control** | `{module}.document_number.control` | التحكم بنظام ترقيم المستندات | جميع الكيانات الرئيسية (100+ كيان في `config/document_numbers.php`) |

### ملاحظات هندسية

- **نظام الترقيم:** `config/document_numbers.php` يحتوي 100+ كيان بscopes: `global` / `company` / `company_period` مع `prefix` + `padding`.
- **النطاق التشغيلي:** `OperatingScopeAccessService` يتحكم بالرؤية عبر `role_company_access`، `role_branch_access`، `role_financial_period_access` pivots مع `admin bypass`.
- **الجلسات:** `OnlineSeatLimitService` يحدد الحد الأقصى 10 مقاعد متزامنة لكل مستخدم.
- **القفل:** `LockScreenService` يدعم قفل الجلسة مع URL عودة.
- **الصلاحيات:** `PermissionRegistryService` تُنشئ ديناميكياً من config/menu + ErpUi screens.

## §22 اختصارات لوحة المفاتيح — Keyboard Shortcuts

### ملاحظة مهمة — Important Disclaimer

> **لم يثبت اختصار ERP مخصص في الكود المفحوص (modules/*/Routes/web.php, config/menu/*.php).**  
> لا يوجد `keydown` handler أو `hotkey` registration في ملفات routes أو config menus المفحوصة.  
> الاختصارات أدناه هي **مستويات نظام تشغيل / متصفح** وليست اختصارات ERP مخصصة.

### اختصارات نظام التشغيل / المتصفح — OS / Browser Shortcuts

| الاختصار | الوظيفة | النطاق | ملاحظات |
|---|---|---|---|
| `Ctrl+C` | نسخ | نظام التشغيل / المتصفح | مُعرّف على مستوى OS. يعمل في حقول الإدخال والنصوص المحددة. |
| `Ctrl+V` | لصق | نظام التشغيل / المتصفح | مُعرّف على مستوى OS. |
| `Ctrl+X` | قص | نظام التشغيل / المتصفح | مُعرّف على مستوى OS. |
| `Ctrl+Z` | تراجع | نظام التشغيل / المتصفح | مُعرّف على مستوى OS. يعمل في حقول الإدخال. |
| `Ctrl+A` | تحديد الكل | نظام التشغيل / المتصفح | مُعرّف على مستوى OS. |
| `Esc` | إلغاء / إغلاق | المتصفح | يُغلق القوائم المنسدلة والنوافذ المنبثقة في الواجهة. |
| `Alt+F4` | إغلاق النافذة | نظام التشغيل (Windows) | ⚠️ **ليست اختصار ERP** — اختصار نظام التشغيل فقط. لا توجد علاقة بتطبيق ERP. |
| `F5` | تحديث الصفحة | المتصفح | يُعيد تحميل الصفحة الحالية. |
| `Ctrl+F` | بحث في الصفحة | المتصفح | يفتح حوار بحث المتصفح. |
| `Ctrl+P` | طباعة | المتصفح | يفتح حوار طباعة المتصفح. |
| `Tab` | التنقل بين الحقول | المتصفح / نظام التشغيل | ينتقل للحقل التالي في ترتيب النموذج. |
| `Shift+Tab` | التنقل للخلف | المتصفح / نظام التشغيل | ينتقل للحقل السابق. |
| `Enter` | تأكيد / إرسال | المتصفح / نظام التشغيل | يُرسل النموذج النشط أو يُؤكد الإجراء. |

### اختصارات متصفح الشاشة الكاملة — Full Screen

|---|---|---|
| `F11` | تبديل وضع الشاشة الكاملة | مُعرّف في المتصفح. مفيد لشاشات العرض (Task Boards Display). |
